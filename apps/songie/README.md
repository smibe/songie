# Songie Flutter application

This is the cross-platform Flutter client for Songie. The current first slice includes:

- A searchable demo song library (temporary; the planned production source is a shared Firestore catalog).
- A phone song reader and tablet two-pane library/reader layout.
- ChordPro chord labels rendered as plain text above lyric positions.
- Persistent chord visibility and lyric text-size settings.
- Full-screen performance mode with temporary controls and screen-awake support.

The demo songs are original sample content, not a commercial lyrics catalog.

## Generate platform projects

The Dart application files are committed, but platform-specific project scaffolding is generated by Flutter on the development machine. From this directory run:

```sh
flutter create --empty --platforms=android,ios,web .
```

This creates the Android, iOS, and web runner projects without replacing the application code in `lib/`.

## Run in a browser

After generating the web runner (the platform-generation command above includes it), start Chrome or Edge and run:

```sh
flutter devices
flutter run -d chrome
```

To create an optimized web release:

```sh
flutter build web --release
```

The deployable files are written to `build/web`. They can be hosted on Firebase Hosting or another static web host. Firebase Hosting configuration and deployment will be added once the Firebase project is connected.

## Get dependencies and run

```sh
flutter pub get
flutter analyze
flutter test
flutter run
```

To run against a connected device, select it with `flutter devices` or pass `-d <device-id>` to `flutter run`.

## Notes

- The ChordPro package is a local path dependency at `../../packages/chordpro`.
- User display preferences are stored locally with `shared_preferences`.
- Performance mode hides system UI and enables a screen wakelock with `wakelock_plus`.
- Firebase is not connected yet. The current app uses in-memory demo songs. The shared catalog design is documented in `../../docs/firestore-catalog.md`; public users will read published songs, while catalog writes will be admin-only.
